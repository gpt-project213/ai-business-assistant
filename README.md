# AI Business Assistant — интеграция ИИ в управление задачами и совещаниями

Система для руководителя: ИИ помогает ставить задачи, разбирать совещания, раздавать поручения и контролировать исполнение. Публичная витрина: описание и архитектура, без боевого кода.

## Интеграция ИИ

- **Совещания:** голос/текст совещания превращается в протокол и список поручений с исполнителями и сроками (модуль совещаний).
- **Раздача поручений:** поручения из совещания создаются как задачи и уходят исполнителям в Telegram.
- **Взаимодействие:** исполнитель отчитывается текстом, голосом, фото или файлом; ИИ разбирает голосовые отчёты.
- **Контроль:** напоминания, просрочки, история изменений, нагрузка по сотрудникам.
- **Аналитика для руководителя:** задачи на сегодня, просрочки, выполнение за день.

## Компоненты

Telegram-бот (руководитель и исполнители), веб-кабинет с доской задач, календарём и отчётами, планировщик напоминаний, ролевая модель с иерархией доступа, резервное копирование.

## Технологии

Python, FastAPI, aiogram, SQLAlchemy + Alembic, APScheduler, распознавание речи, LLM-API.

## Место в общей системе: дашборд компании

Проект — один из модулей единой ИИ-платформы управления. Все модули отдают данные в общий дашборд руководителя.

| Блок дашборда | Модуль | Статус |
|---|---|---|
| Финансы, дебиторка, продажи | ai-management-dashboard | работает (внутренняя эксплуатация) |
| Задачи, контроль исполнения, совещания | ai-business-assistant | работает (внутренняя эксплуатация) |
| Подбор персонала | ai-recruiter-agent | пилот запущен на сервере |
| Заказы и диспетчеризация | ai-crm-dispatch | в эксплуатации у клиентов (Pro) |
| Данные учёта из 1С | ai-1c-integration | в разработке |

Статусы указаны честно: «дашборд компании» — целевая архитектура, не все блоки ещё подключены.
